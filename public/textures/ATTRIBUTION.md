# Texture attribution

`earth-blue-marble.jpg`: NASA Blue Marble (Visible Earth, NASA Goddard Space Flight Center). Public domain. 4096x2048 equirectangular, longitude -180 at the left edge, Greenwich in the center. This copy was taken from the `three-globe` npm package (v2.45.0) example assets.

`earth-night.jpg`: night-side texture with city lights, 4096x2048, same projection. Taken from the `three-globe` npm package (v2.45.0, MIT) example assets, where it is presented as NASA night imagery (Earth at Night / Black Marble, public domain). Its exact NASA source isn't documented there; replace it with a copy downloaded directly from NASA Earth Observatory if exact provenance matters.

`*-2k.jpg`: the same images resized to 2048x1024 (Lanczos, JPEG quality 85) for screens narrower than 1024 px.
